# Desafio-DIO-Planejando-Automa-es-com-n8n-Usando-Bons-Prompts
Projeto desenvolvido para o Desafio DIO, com foco no planejamento de automações utilizando n8n e Engenharia de Prompts. Apresenta uma solução para triagem de riscos corporativos, integrando formulários, Google Sheets e Gmail, com validação de dados, classificação de solicitações e notificações automáticas.
